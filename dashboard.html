Deploy Instructions

Connect Your Devices

Linux/macOS

curl -fsSL https://tailscale.com/install.sh | sh
tailscale up --login-server https://headscale.publicvm.com

Windows

# Download Tailscale from tailscale.com
# Run and use login server: https://headscale.publicvm.com

Docker

docker run -d --name=tailscale \
-v /var/lib/tailscale:/var/lib/tailscale \
-v /dev/net/tun:/dev/net/tun \
--network=host \
--privileged \
tailscale/tailscale tailscale up \
--login-server=https://headscale.publicvm.com
Note: After running the command, check your nodes tab for the new device.
